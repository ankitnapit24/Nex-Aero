# Dataset Card: NASA Turbofan Engine Degradation Simulation (C-MAPSS)

## Dataset Summary
The NASA Commercial Modular Aero-Propulsion System Simulation (C-MAPSS) dataset is a gold standard benchmark for prognostic Remaining Useful Life (RUL) estimation in aviation engineering. The FD001 subset simulates turbofan engine degradation under sea-level operating conditions with a single failure mode (High-Pressure Compressor degradation).

## Provenance and Source
- **Originating Body:** NASA Prognostics Center of Excellence (PCoE), NASA Ames Research Center.
- **Source Repository:** [NASA Prognostics Data Repository](https://ti.arc.nasa.gov/tech/dash/groups/pcoe/prognostic-data-repository/)
- **Authors:** A. Saxena and K. Goebel (2008). "Turbofan Engine Degradation Simulation Data Set", NASA Ames Prognostics Data Repository.
- **Subset Selected:** `FD001`
  - Training units: 100 engines (run until failure / run-to-failure trajectories).
  - Test units: 100 engines (trajectories truncated prior to failure).
  - Operating conditions: 1 (Sea Level).
  - Fault modes: 1 (HPC degradation).

## Target Definition: Remaining Useful Life (RUL)
- **Uncapped RUL:** For training engine $i$ at operating cycle $t$:
  $$RUL(i, t) = \max(\text{cycle}_i) - t$$
- **Piecewise Linear (Capped RUL):** In real turbofans, wear is negligible in early cycles until degradation initiates. A standard benchmark cap (e.g. $RUL_{\text{max}} = 125$) is supported as a documented configurable parameter.

## Intended Use and Disclaimers
This dataset is utilized exclusively for educational, benchmark, and algorithmic demonstration purposes. Predictions generated by models trained on this dataset must never be interpreted as certified airworthiness assessments or real-world aircraft maintenance approvals.
